## 👋 Olá! Eu sou o Luiz Felipe!

Sou Técnico em Informática e Desenvolvedor de Software formado pela Etec da Zona Leste, com foco no desenvolvimento de aplicações back-end e grande interesse por arquitetura e engenharia de software.

Atualmente, trabalho principalmente com Java e Spring, buscando desenvolver sistemas escaláveis, resilientes, eficientes e de fácil manutenção. Tenho especial interesse por microsserviços, sistemas distribuídos, integração entre sistemas e padrões arquiteturais.

Este perfil reúne alguns dos meus projetos, estudos e experimentos — tanto para colocar conceitos em prática quanto para explorar diferentes abordagens de desenvolvimento e arquitetura de software.
